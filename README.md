# SegurExpert Euskadi - Sitio Web Corporativo

## 📋 Descripción del Proyecto

Sitio web profesional, elegante y sobrio para **SegurExpert Euskadi**, una consultoría especializada en gestión de riesgos, emergencias y planes de autoprotección en el País Vasco.

La web está diseñada para proyectar confianza, profesionalidad y expertise en el sector de la seguridad corporativa, con un enfoque inicial en Euskadi pero con visión de expansión nacional e internacional.

## 🚀 Cómo Usar Este Proyecto

### Opción 1: Visualización Local
1. Descarga todos los archivos del proyecto
2. Abre `index.html` en tu navegador web
3. ¡Listo! La web funciona sin servidor

### Opción 2: Publicación en Web
Para publicar la web online:
1. Ve a la pestaña **"Publish"** (Publicar)
2. Haz clic en **"Publish Project"**
3. Recibirás una URL pública para compartir

### Personalización:
- **Colores**: Modifica las variables CSS en `css/style.css` (líneas 1-30)
- **Contenido**: Edita el texto directamente en `index.html`
- **Funcionalidades**: Ajusta comportamientos en `js/main.js`

3. **Compatibilidad**: La web funciona en todos los navegadores modernos (Chrome, Firefox, Safari, Edge).
